# Support

## Getting help

| Need | Where |
| --- | --- |
| How-to / usage questions | [GitHub Discussions](https://github.com/kakathinh42/k7e/discussions) |
| A reproducible bug | [GitHub Issues](https://github.com/kakathinh42/k7e/issues) (use the bug template) |
| A feature idea | [GitHub Issues](https://github.com/kakathinh42/k7e/issues) (use the feature template) |
| A **security** issue | [`SECURITY.md`](SECURITY.md) — private report, **not** a public issue |

## Before you file

- Search existing issues and discussions first.
- For bugs: include the k7e version, OS, and a minimal reproduction. The
  [`docs/getting-started/quickstart-offline.md`](docs/getting-started/quickstart-offline.md)
  demo is the easiest way to produce a reproducible case.
- Read [`ARCHITECTURE.md`](ARCHITECTURE.md) and
  [`docs/operations/security-hardening.md`](docs/operations/security-hardening.md)
  — many "it doesn't work" reports turn out to be local-dev defaults that are
  intentionally not production-safe.

## Response expectations

k7e is maintained by a small team. We aim to triage new issues within
**5 business days**. Security reports follow the SLA in [`SECURITY.md`](SECURITY.md).
